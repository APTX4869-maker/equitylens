# EquityLens 用户全流程验收（2026-09-18）

## 目标与方法

以第一次使用平台的普通用户视角验证“能否理解、能否完成、出错后能否恢复”，不以单元测试通过代替真实浏览器体验。正式数据库仅做只读检查；会改变任务状态的场景使用隔离数据目录或浏览器拦截，保留现有 AAPL、MSFT、NVDA 数据。

问题分为两类：

- **代码缺陷**：行为违背现有产品约定或接口契约；测试完成后先写失败回归测试，再修复。
- **设计缺口**：现有约定本身无法让用户完成目标，或需要新增产品决策；汇总证据后与用户讨论，不擅自扩大产品边界。

严重度：P0 阻断核心目标；P1 核心流程不可用或会误导；P2 有恢复路径但体验明显受损；P3 轻微一致性/可访问性问题。

## 问题汇总

### 设计缺口（需产品确认）

1. **P0：新公司适配没有网页闭环。** 无预置 profile 的公司永久停在 `NEEDS_ADAPTATION`；真实 O09/O10 不可到达。
2. **P1：没有全局任务状态入口。** 刷新或关闭弹窗后，用户不知道 NVDA 仍存在、是否运行、是否需要操作。
3. **P1：任务详情没有用户可理解的时间线。** 缺少已完成步骤、暂停/运行区分、最后更新时间和责任方。
4. **P1：新鲜度语义混合。** “数据截止日”与“最近抓取/刷新时间”没有分开；刷新无新财报时日期不变，用户会误判刷新失败。
5. **P2：64 秒刷新缺少模块级实时进度。** 最终结果正确，但中途只有“刷新中”。

### 明确代码缺陷（本轮已修复）

1. **P1：人工暂停态轮询与错误动作提示。** 改为明确暂停，仅运行态轮询，且按真实动作提示人工适配。
2. **P1：不支持证券的身份显示矛盾。** 基于 SEC 名称/SIC 标识 ETF、FUND、SPAC，并统一中文拒绝原因。
3. **P1：已发布证券重复建档。** 服务端新增 `ALREADY_PUBLISHED` 门禁，避免生成第二个任务。
4. **P2：建档任务列表失败没有重试入口。** 新增原地重试、加载态和错误 `alert`。
5. **P2：移动端概览横向溢出 9px。** 限制网格子项最小宽度，390px 视口不再越界。
6. **P2：发现错误显示技术字符串。** 用户错误统一提取消息，非法 ticker 使用中文说明。
7. **P3：证据按钮暴露截断内部 ID。** 按钮改为“查看证据”，内部 ID 只用于请求溯源链。

以上缺陷均先新增可复现失败测试，再实现修复；新增 7 个浏览器回归场景、3 个后端回归场景，并补强 ETF 分类断言。
