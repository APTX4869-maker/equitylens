# 公司建档用户指南

本功能用于申请一个尚未出现在 EquityLens 公司目录中的美国上市经营公司。申请不等于发布：公司只有在 SEC 身份核实、数据采集、专属配置、质量检查和维护者复核全部完成后才会出现在目录里。

## 启动

前置条件：已从锁文件安装 Python 与前端依赖、本机可访问 SEC、维护者已配置带真实联系方式的 `EQUITYLENS_USER_AGENT`。普通申请人不需要编辑 profile 或数据库。

在仓库根目录启动 API：

```bash
uv run uvicorn equitylens.api.main:app --port 8000
```

另开终端启动页面：

```bash
pnpm --dir apps/web dev
```

打开 `http://localhost:3000`。联网发现前，维护者需按维护指南配置 SEC User-Agent。

## 申请公司

1. 点击侧栏或移动端顶部的“添加公司”。
2. 输入股票代码，例如 `KO`，点击“识别公司”。
3. 核对 SEC 返回的法定名称、交易所、证券类型和覆盖期间。存在多股类或 ticker 歧义时必须选择明确证券，不能只凭公司名继续。
4. 点击“确认并建档”。重复点击或网络重试会复用同一个幂等申请，不会创建重复任务。
5. 在“建档中心”查看步骤、修订号、候选数据、质量检查和明确的下一步。

任务通常依次显示“排队中”“抓取 SEC 资料”“构建公司档案”“运行质量检查”“等待维护者复核”和“已发布”。没有发行人专属数据 profile 时停在“等待适配”；这是发布前的维护工作。可重试的采集错误会显示原因和重试操作。页面可见时约每 2 秒更新，隐藏标签页时降低到约每 10 秒，终态停止轮询。

## 如何理解结果

- 公司目录只列出已有 publication 的公司。候选、质量失败或仅获批准但未完成原子发布的数据都不会出现。
- “数据阻断”表示正式财务或估值能力缺少证据，不能通过改页面参数绕过。
- 估值页的“待配置”与“等待适配”不是同一状态：前者表示公司数据已经发布，但证券、币种、ADR、模型或假设指纹尚未确认；完成估值假设配置前不能运行正式估值。
- 每次正式读取都固定到 company、security 和 publication。切换公司后，旧请求即使较晚返回也不会覆盖当前页面。

## 常见问题

发现失败时先确认代码正确、网络可访问 `data.sec.gov` 与 `www.sec.gov`，并联系维护者检查 SEC User-Agent。SEC 拒绝访问时等待后重试，不要绕过其访问策略。任务长期停在“等待适配”表示该发行人尚无经过代码审查的 profile；停在“等待维护者复核”但批准按钮不可用，表示质量报告仍有 BLOCKER。不要把这两种状态当成已建档。

取消任务会保留已完成的不可变证据和 attempt 记录，方便审计；已发布任务不能取消。任务失败后只能针对当前修订重试，若页面提示修订冲突，请重新打开任务后再操作。
