# REST API Contract — Initial Design

Prefix: `/api/v1`

All monetary values are raw numeric base units in API payloads. UI handles B/M formatting.

## 1. Company

### `GET /companies/{ticker}`

Returns identity, CIK, fiscal year end, sector metadata and source freshness.

## 2. Overview

### `GET /companies/{ticker}/overview?as_of=&mode=latest_restated`

Returns:

- latest fiscal period
- KPI summary
- highlight cards
- business mix summary
- operating signals
- risks/watch items

Highlights generated by AI must be separate from raw/derived metrics and include evidence IDs.

## 3. Financial facts

### `GET /companies/{ticker}/facts`

Filters:

- `metrics=REVENUE,NET_INCOME,...`
- `frequency=annual|quarterly|ttm`
- `limit=12`
- `as_of=`
- `view=latest_restated|point_in_time`

Example:

```json
{
  "metric": "REVENUE",
  "period": "FY2026Q3",
  "period_type": "Q_STANDALONE",
  "value": 94000000000,
  "unit": "USD",
  "status": "NORMALIZED",
  "provenance": {
    "source_document_id": "src_...",
    "provider": "SEC",
    "form": "10-Q",
    "accession": "...",
    "filed_at": "...",
    "concept": "us-gaap:...",
    "context_id": "...",
    "source_url": "...",
    "mapping_version": "revenue.usgaap.v1"
  }
}
```

## 4. Derived metrics

### `GET /companies/{ticker}/metrics`

Returns formula metadata:

```json
{
  "metric": "FCF_MARGIN",
  "value": 0.267,
  "status": "CALCULATED",
  "formula": "FCF / REVENUE",
  "formula_version": "fcf_margin.v1",
  "input_fact_ids": ["...", "...", "..."],
  "provenance_url": "/api/v1/provenance/metric_value_id"
}
```

## 5. Segments

### `GET /companies/{ticker}/segments?frequency=quarterly&limit=8`

Each segment item must expose:

- company-reported segment/product name
- analytical mapped name if used
- revenue/share/growth
- disclosure status for profitability
- source facts/evidence

## 6. Management

### `GET /companies/{ticker}/management`

Returns:

- leaders
- six-dimensional scorecard + rubric coverage
- strategy events
- capital allocation metrics
- shareholder alignment
- governance
- Promise Tracker
- watch items

## 7. Valuation

### `GET /companies/{ticker}/valuation/default`

Returns current configured default valuation snapshot.

### `POST /companies/{ticker}/valuation/run`

Request:

```json
{
  "model": "FCFF_DCF_V1",
  "scenario": "CUSTOM",
  "assumptions": {
    "revenue_growth": [0.08,0.075,0.07,0.06,0.05],
    "operating_margin_year5": 0.32,
    "wacc": 0.085,
    "terminal_growth": 0.025
  }
}
```

Response must include:

- fair value/share
- year-by-year forecast
- enterprise/equity value bridge
- assumption metadata
- source snapshot IDs
- warnings

### `POST /companies/{ticker}/valuation/reverse-dcf`

Solves a selected implied variable under explicit fixed assumptions.

## 8. Provenance

### `GET /provenance/{entity_id}`

Returns lineage recursively: calculated value -> normalized facts -> raw facts -> source document.

### `GET /sources/{source_document_id}`

Returns source metadata and official URL. Raw cached file access may be a separate protected/dev endpoint.

## 9. Evidence

### `GET /evidence/{evidence_id}`

Returns document, section, paragraph/span, source URL and text within permitted limits.

## 10. Research assistant

### `POST /research/ask`

LLM response schema:

```json
{
  "answer": "...",
  "claims": [
    {
      "claim": "...",
      "confidence": "HIGH",
      "evidence_ids": ["ev_1","ev_2"]
    }
  ],
  "metric_ids": ["mv_..."],
  "limitations": []
}
```

Reject a “factual” claim from the final answer if required evidence IDs cannot be resolved.
